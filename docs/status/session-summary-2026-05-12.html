deferred / out-of-scope (honest)

HF fine-tuning execution

Real GPU fine-tuning needs 4–8 h on a beefy box. The bundle (data + config + instructions) is ready; architect launches on Colab / Kaggle / HF AutoTrain in parallel.

Per-agent regression models / activation functions

Mörbius agents are LLM-call wrappers, not classical ML pipelines. A "perfect activation function per agent" is a category swap that needs an architecture conversation, not a one-day code change. The calibrator (isotonic regression on gauntlet thresholds) and the sequential-error-correction loop (residual journal at docs/status/boosting-journal.jsonl) are the closest analogues currently shipped.

Live booking + insurance feeds

Data shape is realistic (12 named clinicians, 7 plans scored across 6 axes) but the integrations to a real booking API or live insurance offer-sheet data need partnerships. The recommender is wired to bias on the patient's actual ICD-10 codes, so the recommendation is non-trivial today.

Voice consistency

Investigated but not patched. voice.ts already pins by (lang, identity) and applies per-identity prosody. Architect's complaint about variation is likely the intentional per-tone prosody (warm doctor adapts) — flagged as a tune, not a bug, waiting on specific feedback on which surface sounds wrong.
