## ✦ The reshape claim

Most "medical AI" shipping today is a chatbot reskin with a stethoscope emoji. Mörbius is the opposite:

- **Local-first by default.** Ollama runs the diagnostic. Cloud APIs are fallback.
- **Six specialist agents** (cardio · neuro · onco · pulmo · endo · derma) routed by triage; cross-validated by a unified DiagnosticAgent.
- **Validator → Safety → Privacy gauntlet** (0.7 / 0.75 / 0.85) on every reply.
- **Graphify-style medical knowledge graph** that grows every cycle — `EXTRACTED` / `INFERRED` / `AMBIGUOUS` confidence tags so the system never buries inference as fact.
- **HIPAA Ed25519 audit-signed** activity log with chain integrity verification.
- **Federated learning ready** — clinics keep local data, share only weight deltas.
- **Quantum-augmented** ensembles via Qiskit Aer simulator + IBM Quantum Open Plan path.

## ✦ Architecture (one paragraph)

Bun + Hono + React 19 monorepo. Ollama (Meditron · Llama-3.2-3B) is the default diagnostic backend; NVIDIA NIM · HuggingFace · Anthropic are fallbacks via priority list. FastAPI sidecar (py-svc) hosts MONAI imaging · MarianMT translation · scispaCy NER · Qiskit Aer quantum routers. Postgres + pgvector for memory · Qdrant cluster for retrieval · Redis for queues. The agent mesh streams via Hono SSE; every reply is signed by an Ed25519 audit signer (`AUDIT_LOG_SIGNING_KEY`). Continuous learning is a graphify-style daily research-cycle that ingests yesterday's consults + fresh PubMed abstracts, builds the knowledge-graph delta, and triggers a QLoRA fine-tune on free Colab T4 — pushed to HuggingFace Hub for the next consult to use. Zero monthly budget.
